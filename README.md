# 💻 LeetCode Problems

A collection of **LeetCode problems solved in C++**, along with my personal **handwritten notes** documenting how I approached each problem.

This repository is not just about collecting solutions it's about understanding **how to think through a problem**, starting from the brute-force approach and working towards an optimized solution.

## 📖 About

Every problem in this repository includes:

* 💻 The C++ solution
* 📝 Handwritten notes
* 📜 Problem statement
* 🧠 Main approach and solution
* 🐢 Brute-force approach
* ⚙️ Algorithm
* 💡 Important observations and points
* ⏱️ Time Complexity
* 📦 Space Complexity

The goal is to document my **problem-solving journey** while building a stronger understanding of **Data Structures and Algorithms**.

## 🧠 My Approach

For each problem, I try to break it down step by step:

1. 📖 Understand the problem
2. 🐢 Think about the brute-force solution
3. 🔍 Identify its limitations
4. 💡 Look for important observations
5. ⚙️ Develop a better approach
6. 💻 Implement the solution in C++
7. ⏱️ Analyze time and space complexity
8. 📝 Document the complete thought process in handwritten notes
